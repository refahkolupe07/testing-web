# Hermes Agent workflow

- Keep Opus as the lead for planning, architectural decisions, complex reasoning, and final review.
- Before implementation, make a short plan, then delegate one clearly bounded, low-risk implementation task through `delegate_task`, with complete context, explicit scope, and acceptance criteria.
- Keep heavy, cross-cutting, ambiguous, and high-risk work on Opus. Review the child's changes and reported checks independently, run any necessary validation, and handle integration or corrections.
- Ask the child to inspect nearby code and conventions first, stay within scope, run focused checks when practical, and return a concise report of changes, checks, and caveats.

## Hermes profile settings

Hermes project instructions do not set model or compression settings. In the active Hermes profile, select Opus as the main model and Haiku for subagents under **Settings → Model → Subagents** (or set the documented `model` and `delegation` fields in that profile's `config.yaml`). Set `compression.threshold` to `0.50`, for example with `hermes config set compression.threshold 0.50`. Hermes floors the effective threshold at `0.75` for model context windows below 512K, so the 50% threshold is not honored for those models.
